Mengapa Aplikasi Ini Rentan?

Aplikasi ini menggabungkan input pengguna secara langsung ke dalam string query SQL menggunakan konkatenasi:

$sql = "SELECT * FROM users WHERE user = '" . $input . "'";

Solusi keamanan standar adalah menggunakan Prepared Statements (Parameterized Queries) agar input diperlakukan sebagai literal murni, bukan instruksi kode SQL.
